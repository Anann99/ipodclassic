# Classic

A click-wheel handheld in your browser. Run your thumb around the wheel to scroll, press the
center to choose, press Menu to go back.

- **Orbit**: breakout on a ring. The wheel turns the paddle.
- **Quiz**: ten timed questions. Play solo, or host a room and have friends join with its code.

## Run it

```bash
npm install
npm run dev
```

Open the address it prints. Phones on the same Wi-Fi can open the Network address and join a
Quiz room; nothing needs deploying.

## Controls

| Wheel           | Keyboard              |
| --------------- | --------------------- |
| Turn            | Arrow keys, or scroll |
| Center          | Enter                 |
| Menu            | Escape                |
| Play/Pause      | Space                 |
| Previous / Next | `,` / `.`             |
